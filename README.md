# DSA Shopping System

A desktop application built using C++ and Qt that simulates a shopping system using data structures.

## Features
- User registration and login
- Shop and product management
- Order processing using priority-based queue (deque)
- Save and load system data using CSV files
- Graphical User Interface (GUI)

## Technologies
- C++
- Qt Framework
- Data Structures (Vector, Queue, Deque)
- File Handling (CSV)

## How to Run
1. Open the project in Qt Creator
2. Open the `.pro` file
3. Run qmake
4. Build and Run
